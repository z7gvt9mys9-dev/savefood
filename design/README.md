# SaveFood — тёмные дизайн-направления

В папке собраны три самостоятельных концепта, основанных на текущей структуре
SaveFood: публичный лендинг, три роли пользователя, карточки лотов, маршруты,
заявки и ESG-метрики.

## Варианты

- `noir` — строгий городской dispatch-подход для сетей и партнёров.
- `ember` — тёплый, человечный образ с акцентом на еду и сообщество.
- `signal` — технологичный продуктовый интерфейс с акцентом на live-данные.

Откройте `index.html` в этой папке, чтобы переключаться между вариантами в
общем сравнительном экране. Каждый вариант можно открыть отдельно через его
собственный `index.html`; сборка и установка зависимостей не нужны.
