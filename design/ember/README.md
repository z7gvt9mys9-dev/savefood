# SaveFood — Ember

Тёплый тёмный дизайн-концепт для публичной части SaveFood с preview трёх
продуктовых кабинетов.

## Идея

Ember использует визуальные ассоциации с печёной корочкой, тёплой кухней и
зрелыми продуктами: почти чёрный «кофейный» фон, оранжевый акцент, мёд и шалфей.
Крупная антиква делает публичную часть человечной, а компактный гротеск сохраняет
плотность и ясность интерфейсов.

В концепте отражены реальные части платформы:

- поток «магазин → волонтёр → получатель»;
- карта лотов и бронирование для получателя;
- оптимизированный маршрут с QR-подтверждением для волонтёра;
- лоты, OCR чеков и ESG-показатели для магазина;
- публичный impact-дашборд;
- FAQ, регистрация по ролям и контакты.

Все показатели помечены как демонстрационные.

## Запуск

Откройте `index.html` двойным щелчком в браузере. Сборка и установка
зависимостей не нужны.

Также можно запустить любой локальный статический сервер из этой папки.

## Интеракции

- адаптивное мобильное меню;
- переключатель продуктового preview с клавишами `←` и `→`;
- выбор лота на карте и в карточках;
- демонстрационные действия с уведомлениями;
- нативные доступные FAQ-аккордеоны;
- модальное окно выбора роли и проверки формы;
- стили для клавиатурного фокуса и режима reduced motion.
