# SaveFood / Noir

Самостоятельный тёмный дизайн-концепт публичного сайта и продуктовой части SaveFood.

## Что внутри

- лендинг с реальными сценариями «магазин → волонтёр → получатель»;
- интерактивный preview трёх ролевых интерфейсов;
- секция Impact-дашборда с явно обозначенными демонстрационными данными;
- адаптивное меню, FAQ, регистрационный dialog и демо-действия;
- клавиатурная навигация по вкладкам, заметные focus-состояния и поддержка `prefers-reduced-motion`.

## Как открыть

Сборка и зависимости не нужны. Можно просто открыть `index.html` в браузере.

Для просмотра через локальный сервер из корня репозитория:

```sh
python3 -m http.server 4173 --directory design/noir
```

После этого открыть `http://localhost:4173`.

## Файлы

- `index.html` — разметка и контент;
- `styles.css` — визуальная система и адаптив;
- `script.js` — базовые интеракции.
