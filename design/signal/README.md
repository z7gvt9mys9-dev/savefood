# Signal

Тёмное технологичное направление для SaveFood в стилистике городского
операционного центра. Главный акцент — live-статусы, маршруты, лоты, OCR,
ESG-метрики и измеримый вклад платформы.

## Что показано

- публичный лендинг и механика `магазин → волонтёр → получатель`;
- интерактивный preview продуктовой части;
- сценарии всех трёх ролей;
- статистика, impact и FAQ;
- адаптивное меню и диалог выбора роли.

Откройте `index.html` напрямую в браузере. Сборка и внешние зависимости не
требуются.
